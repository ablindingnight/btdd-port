KNUCKLE DRIVE

Your ROM. Our engine. Two fists. A native PC port of a 1993 NES co-op brawler, built on your computer from your own cartridge dump.

The launcher: your ROM verified, your build ready, PLAY.

How to play

  1. You need your own backup of the Battletoads & Double Dragon (USA) NES cartridge as a .nes file (or a .zip that holds it). Knuckle Drive does not include the game and can't get it for you.
  2. Download the latest release and unzip it anywhere. Start KnuckleDrive.exe.
  3. Drag your ROM onto the launcher, or pick it.
  4. The launcher checks it's the USA cartridge, compiles the game into a native program and runs a quick self-check. Then press PLAY.

First run: building your game.

Everything is in the launcher and in game (Esc): window size, widescreen, CRT and smoothing presets, no sprite flicker, two players on keyboard and gamepads, save states, rewind, fast forward, the game's own cheat codes, and online 2-player with join codes.

If something goes wrong: the Logs page lists every run, and Save report makes a folder with the logs and your settings (your user name removed). Nothing is sent anywhere.

What's in the download

The launcher, the game engine (btdd_play.exe), the compiler used on first run (libtcc.dll), the game description file (btdd.meta: names, addresses and code layout, no bytes from the cartridge), and our fonts and art.

No game data here

No code, graphics, music or text from the cartridge, and no ROM. The engine reads your ROM and compiles it on your PC. Every release is scanned for cartridge bytes before upload. Not affiliated with or endorsed by the game's publishers or by Nintendo; game names are used only to say which ROM you need.
